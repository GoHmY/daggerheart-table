# Table Daggerheart

Application de table pour Daggerheart : création guidée de personnage, fiches évolutives, inventaire, effets, dés réels ou virtuels et écran du MJ.

- Version web installable : https://gohmy.github.io/daggerheart-table/
- APK Android : https://gohmy.github.io/daggerheart-table/telechargements/Daggerheart.apk

Les fiches sont enregistrées sur chaque appareil. Utilisez « Télécharger mes fiches » pour les sauvegarder ou les partager.
